# Massacote's Blog

A personal blog where I write about the things I'm learning — mostly backend engineering, but really whatever I'm curious about at the moment.

## Why this exists

I've always learned best by writing things down. This blog is where that habit lives in public: notes from things I've built, problems I've chased down, and ideas I keep coming back to. If something here helps you think through a problem of your own, that's the best outcome I could ask for.

## About me

I'm Marcos, a backend developer who genuinely loves this craft. I spend most of my time with Python — building APIs, wiring up integrations, and lately getting into production AI. More than any specific tool, what keeps me going is the habit of getting a little better every day, and understanding *why* something works, not just that it does.
